# Submission: Space IFIC 3074 and Terrestrial BR IFIC 3076

These are the processed results for the two accuracy-evaluation issues of the Traficom challenge. Every file
was generated by the tool's CLI from the ITU `.mdb` files with no hand edits. The evaluation date (`as_of`) is
2026-11-07. Space notices use model `riia-1` and terrestrial assignments use `terra-1`.

No result is a score. Each finding is an outcome: `exceeds`, `meets`, `screened_out`, `not_applicable` or
`not_assessed`. Every finding comes with the numbers, assumptions and source citations behind it.

## Where to start

1. **Space 3074:** `space-3074/concerns-3074.md`. These are the notices an expert should review, in priority
 groups. The `.csv` beside it has the same rows plus empty `reviewer_verdict` and `reviewer_note` columns for
 recording a judgement.
2. **Terrestrial 3076:** `terra-3076/terra-3076.md`. These are the foreign land mobile assignments that may affect
 Finland, with the P.1546 field strength at the Finnish border for each one.

## Space IFIC 3074

The tool assesses every notice (196) against two receiver populations:

- **`stations`**: the frequencies-of-interest dataset (the synthetic special-interest station list), with the
real location, band, height, azimuth and gain of each station.
- **`generic-m4`**: every protected service in the Finnish M4 allocation table, placed on a grid over Finland.
It overstates exposure, because it assumes every service is deployed everywhere. Use it to check coverage,
not as the finding.

| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `concerns-3074.md` / `.csv` | Concern triage over both populations, in four groups (below)                                                                                                                       |

## Terrestrial BR IFIC 3076

There are 1858 foreign land mobile assignments (station class FB or ML), of which 57 are relevant to Finland.
Outcomes: 6 exceed, 3 meet, 39 are screened out, 1810 are not applicable and 0 are not assessed. All 6 exceedances
are new Russian base stations at 152–153 MHz, 30–42 km from the border: two at Kostomuksha, one at Lyaskelya and
three at Vyborg.


| File                   | Contents                                                                                                                                                  |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `terra-3076.md`        | Readable findings per assignment: source notice, change class, criterion, trigger, E at the worst Finnish point, margin, model parameters and assumptions |
| `terra-3076.csv`       | One row per assignment, all 1858. Filter on `relevant=true` to get the 57 that the UI shows by default                                                    |
| `terra-3076.json`      | The full canonical result per assignment, including the stored P.1546 inputs that reproduce E                                                             |
| `assessment-3076.json` | The same content as `terra-3076.json`, written by `terra-assess --json`                                                                                   |


CSV columns that matter most:

- **`change`**: `new`, `modified` or `withdrawn`.
- **`pub_status`**: `received`, `recorded` or `returned`.
- **`criterion_id` and `applicability`**: for example ECC T/R 25-08. RUS is marked `indicative` because Russia's
CEPT membership is suspended.
- **`trigger`**: the trigger level in dB(µV/m).
- **`e_dbuv`**: the P.1546 field strength at the worst Finnish border point.
- **`margin_db`**: E minus the trigger. A positive margin means `exceeds`.
- **`assumptions`**: assumption ids, defined in `docs/terrestrial-land-mobile.md`.
- **`sources`**: the IFIC table and key of every input row, so each value can be traced to the `.mdb`.
