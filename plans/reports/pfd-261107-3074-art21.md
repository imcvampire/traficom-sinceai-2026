# pfd vs RR Table 21-4 on IFIC 3074 (dry run)

The check `art21-1` finds that **47 of the 196 notices of IFIC 3074 exceed an RR Table 21-4 limit** somewhere on
Finnish territory under its stated assumptions, and 31 are within 3 dB of a limit. Every one of the 108 exceeding
checks is a calculated pfd that uses the satellite's **peak gain toward Finland** (3074 notifies no beam boresights),
and with the satellite gain lowered by 10 dB, 31 of the 47 no longer exceed. These results therefore mark the
notices worth a closer look; they are not findings. The Table 21-4 transcription is still pending review.

## How the run was made

- Code: the working tree of 2026-11-07 (pfd check `art21-1`, model `riia-1`). `as_of` 2026-11-06.
- The API dev server held the DuckDB lock, so the run used a copy of `var/db/ific.duckdb` (`IFIC_DB_DIR` in the
  scratchpad). 3074 was re-ingested there automatically, because the table set now includes `srv_cls`. Then the
  following ran: `ific assess 3074` for `generic-m4` and `stations`, and `ific review 3074`. The stored results in
  `var/db` were not changed.
- Review report and CSV from that run: [review-261107-3074-pfd.md](review-261107-3074-pfd.md),
  [review-261107-3074-pfd.csv](review-261107-3074-pfd.csv).
- The pfd check does not depend on the receiver source, and the two runs produced identical `pfd_checks`.

## Data issue found during the run

The first run gave an implausible +122.5 dB margin (LVI, 2.2 GHz). The cause is `emiss.pwr_ds_max = +73` dB(W/Hz)
for a carrier with `pep_max = −4` dBW, almost certainly a sign error for −73. 91 emissions in 3074 have a
`pwr_ds_max` that puts more power in its AP4 averaging band than `pep_max` in the whole carrier. The check now
treats such a value as a data error and uses `pep_max` (assumption `pfd_density_inconsistent`). The hazard path
already used `pep_max` first, so it was not affected. The limits and margins were not tuned.

## Reading these results

- A GSO exceedance at δ ≈ 5–12° (northern Finland seeing a satellite low on the horizon) with peak gain is an upper
  bound. A satellite whose beam serves another region delivers much less gain toward Finland. Notified boresights
  or gain contours are needed to settle it.
- Non-GSO exceedances at δ = 90° assume a high-gain beam pointed straight down at Finland from the lowest altitude.
- Several networks appear twice under paired ntc_ids (for example 124520174 and 324520174), as they do in the hazard
  results.
